Middle Name Alias Encoder

Encode a website name into a plausible fake middle name.

This app uses a reversible Vigenere-style cipher over letters only, then shapes the result into title case so it looks like a name rather than raw gibberish. It is meant for personal tagging and recall, not for serious privacy or cryptography.

Example: with a secret phrase and a site label like ExampleShop, the app can output something like Marolen. Using the same secret phrase later, you can decode that alias back to the original site label.

How it works

1. Normalize the website name to letters only. 2. Encrypt letters with your secret phrase. 3. Split into vowel-friendly chunks and title-case the result. 4. Store nothing locally.

Limits

Secret phrase: 2-32 characters. Website label: 2-24 letters after cleanup. The alias preserves reversibility but still may look unusual on strict forms.
